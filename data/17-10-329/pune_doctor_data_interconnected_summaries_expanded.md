**Data rules**
- Additional biographical detail is included only where an official hospital profile or directory explicitly states it. Missing experience, qualifications, languages, and schedules remain unfilled rather than guessed.
- The hospital affiliation is included only when an official hospital doctor directory, department faculty page, or doctor profile supports it.
- A doctor can be linked to multiple hospitals only when a source explicitly supports each affiliation (for example, Dr. Hemant Wakankar’s Deenanath profile also names Ruby Hall Clinic).
- Where a schedule is not published, the file says so and directs the developer to the official appointment route. It does not invent OPD timings.
- Do not infer personal WhatsApp numbers or laboratory connections.
- This is a curated starting set of 30 doctors, not an exhaustive list or an objective ranking of “most trusted” clinicians.

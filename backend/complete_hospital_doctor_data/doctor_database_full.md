# Medvexa — Interconnected Doctor Database (India)

**Dataset version:** 1.0 · **Prepared:** 20 October 2026

Doctor profiles are connected to the hospital database using stable IDs. A doctor is linked to a hospital only where an official hospital directory, official profile or institutional roster supports the relationship. This curated initial roster contains doctors surfaced in the official source research completed for this release; it is not an objective ranking of the “best” doctors in India.

**Important integration rule:** One person should have one canonical doctor record. Add every supported hospital affiliation to that record rather than duplicating the person. Consultation schedules change; display only the schedule stated below and keep the institution’s booking link as the live appointment route.
